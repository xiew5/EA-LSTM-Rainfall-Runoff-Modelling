This folder contains the collated dataset of gauged flow time series and catchment average meteorological datasets used in the development of CERF2-HadUK as described within WHS (2024 - https://www.hydrosolutions.co.uk/app/uploads/2024/04/Development-of-CERF2-HadUK-v2.pdf). The gauged flow time series are for catchments in England that were labelled as ‘non-urban’ during the CERF2-HadUK calibration. The source of this data is the NRFA, and these were downloaded to include data up to the end of December 2021. Catchment average rainfall and PE for each gauge were derived by WHS based on the HadUK and UKCEH PE datasets as defined within the aforementioned report.

Folder "Climate_Data.zip" includes the catchment average rainfall and PE.
Folder "NRFA_Restrival_Apri2024.zip" includes the NRFA flow timeseries in m3/s.
File "EA_CERF_Calibration_GSTN_RemoveUrban.csv" is a list of the gauging stations for which the data is provided.
